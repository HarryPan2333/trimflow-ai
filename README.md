# TrimFlow AI

**AI-Powered Sales & Order Execution Workspace for Global Apparel Trims**

> Beta v0.7 · Independent 0→1 Product Prototype · Synthetic Data Only

TrimFlow AI is an independent 0→1 product prototype exploring how structured workflow software and AI can support B2B sales execution in apparel trims and foreign trade.

It connects product development, commercial negotiation, and order execution in one workspace—so sales teams can see the current situation, understand what is blocking progress, and decide what should happen next.

## Live Demo

[Open TrimFlow AI](https://trimflow-ai.vercel.app)

The interface currently provides a Chinese-first experience. English localization is in progress.

## Why I Built It

Sales workflows in traditional B2B and foreign-trade environments can become fragmented across:

- Spreadsheets
- Chat and email
- Sample tracking sheets
- Quotation files
- Order documents
- Individual salesperson memory

This prototype explores how those sources of context could be connected into an execution-focused workspace. The product is designed around the practical handoffs between a client request, physical sample development, commercial negotiation, and order delivery.

## Product Philosophy

TrimFlow is not intended to be another generic CRM.

The workspace is organized around three operational questions:

1. What is happening?
2. What is blocking progress?
3. What should happen next?

AI is intended to operate on top of structured business context rather than exist only as a standalone chatbot. Samples, quotations, communications, tasks, and orders provide the evidence layer for useful assistance.

## AI Transparency

The current Beta uses deterministic prototype logic and synthetic business context for many:

- Risk signals
- Readiness checks
- Commercial and deal strategies
- Next-best-action suggestions

The project AI assistant also preserves a mock fallback mode. An optional server-side OpenAI API integration is present, but this repository does not imply that every recommendation is generated by a production AI model.

Future AI directions may include communication summarization, sample-feedback extraction, negotiation and meeting preparation, sales follow-up drafting, weekly reporting, and account intelligence.

## Run Locally

Requirements:

- Node.js 22.x
- pnpm 10.29.3

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

No API key is required for the prototype experience. To test the optional live project assistant, copy `.env.example` to `.env.local` and provide `OPENAI_API_KEY` as a server-side environment variable. Never expose it with a `NEXT_PUBLIC_` prefix or commit it to Git.

### Build Note

The application currently passes production compilation using the Next.js Webpack build path. A local Turbopack-specific build hang on macOS ARM64 is being investigated; the repository's standard build script and Next.js configuration remain unchanged.

## Deploy to Vercel

1. Import the GitHub repository into Vercel.
2. Keep the Next.js framework preset and the repository's existing package settings.
3. No environment variables are required for the mock prototype.
4. To enable the optional live project assistant, configure `OPENAI_API_KEY` only in Vercel's server-side environment settings.
5. Deploy and verify the generated production URL.
